# Как я провёл лето

Учебный проект по дисциплине «Web-технологии» (ЛР-1: Настройка среды разработки).

Статический сайт на тему «Как я провёл лето»: адаптивная вёрстка, стилизация с помощью Bootstrap.

## Структура проекта

- `index.html` — главная страница сайта
- `assets/` — изображения, используемые на странице

## Как открыть

Скачайте репозиторий и откройте `index.html` в браузере — интернет нужен только для загрузки шрифтов и Bootstrap с CDN.
